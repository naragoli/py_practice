# Todo Expo App (Android-only)

Minimal Expo + React Native todo app (essentials): add, delete, toggle complete, local persistence via AsyncStorage.

## Quick setup

1. Install `npm`/`node` and `expo` CLI if not installed:

```bash
npm install -g expo-cli
```

2. From project folder:

```bash
cd todo-expo
npm install
npm start
```

3. Run on Android emulator or device using the Expo Dev Tools or:

```bash
npm run android
```

## Notes
